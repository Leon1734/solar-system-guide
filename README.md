## ✨ 功能总览

### ✨ 星座神话小传 + 🌙 真实月相（v7.0）
- **神话小传**：点击 3D 星空中的亮星标签或今晚天空的黄道宫，弹出该星座的希腊神话故事卡（含最亮星科普）——猎户与天蝎的宿敌、双子的兄弟情、俄耳甫斯的琴……
- **真实月相**：月球黄经改用 Meeus 低阶理论（14 项摄动），月相望远镜、3D 月球位置与**真实农历日期完全对齐**——输入真实满月日期（如 2024-01-25），看到的就是 99.9% 满月。月相成因终于"真"了。

### ☄️ 流星雨辐射点联动 + 📅 今日提醒（v7.0）
- 今晚天空面板自动列出**当前活跃或 45 天内**的流星雨（象限仪/英仙/猎户/狮子/双子，含母彗星与辐射点星座），点击即跳峰值日并打开沙盘选中该雨。
- 启动时自动检查：今天恰逢日历天象或流星雨峰值，第一时间 toast 提醒。

### ⭐ 星座与黄道带 + 🌙 月相望远镜（v6.0）
- 23 个亮星座连线（黄道十二宫全覆盖 + 猎户/大熊/仙后/天鹅/南十字…），亮星中文名标签（天狼、织女、牛郎、心宿二…），金色黄道参考圈。
- 位置由真实赤经赤纬转黄道坐标，与行星轨道同坐标系——行星真的"走"在星座之间。

### 🌙 月相望远镜（v6.0）
- 当前模拟时刻的真实月相：月龄、照亮比例、八相命名；明暗界线按椭圆几何精确渲染（全八相自洽）。
- 月面地名（雨海/静海/风暴洋/第谷…）只在照亮侧显示；附日-地-月成因几何图。

### 📅 天文日历 + ⏳ 时间轴（v6.0）
- 22 条 1997–2061 关键天象（木土大合、日全食、阿波菲斯掠地、哈雷回归、水星凌日……），点击跳转当天 + 自动运镜 + 解说卡。
- ±100 年对数时间轴拖拽漫游，天象刻度可点击直达。

### 🎲📐🛰️📄 教学与工具（v6.0）
- **每日一题**：20 题随机池，答对累计 ⭐ 积分（本地持久化）。
- **面积定律扇形**：跟随偏心天体（水星/彗星/阿波菲斯）时实时着色"近 30 天扫过区"。
- **卡西尼缝特写**：土星档案卡一键运镜俯瞰光环。
- **CSV 导出**：今晚天空面板导出行星黄经/距角/距离表。
- **公转进度环**：档案卡"海王星自发现以来已绕 X 圈"。

### 👁️ 今晚天空（v5.0 旗舰）
- 由模拟时刻的**真实轨道位置**计算五大行星的距角（太阳-地球-行星夹角），告诉你今晚哪些行星可见、在黄昏西天还是黎明东天。
- 黄昏地平线视角的天空带可视化：太阳在地平线下，行星按距角与方位悬挂，西距角行星标注"明晨东天"。
- 物理已验证：金星距角在 8 年间扫过 0°~47°，与真实会合周期吻合。拨动日期即可预报任何一天的夜空。

## 🔧 技术要点

- **统一开普勒解算器**：行星走 J2000 要素+世纪变率；彗星/矮行星走 M0 平近点角路径，共用牛顿迭代与坐标旋转。
- **彗尾粒子系统**：每帧根据日距计算活动度，离子尾沿反日向、尘埃尾向速度方向弯曲滞后，颜色/尺寸沿尾长衰减。
- **延迟初始化**：加载屏先绘制一帧再生成贴图（约数秒），避免白屏假死；后台标签用定时器而非 rAF 触发。
- **SolarApp API**：`window.SolarApp` 暴露 goto/setDate/setSpeed/setMode/onTick 等，课程与工具模块经此解耦。
- **防御式降级**：Bloom 失败自动回退直渲；真实贴图失败自动回退程序化；localStorage 异常静默忽略。

## ⚠️ 教学说明（比例约定）

- 行星**位置**基于真实轨道数据；**尺寸**相对距离有放大（真实比例下行星小如尘埃）；月球/卫星轨道距离为示意放大。
- 哈雷彗星与矮行星轨道为科普级近似要素（精度足以演示形态特征与回归周期）。
- 日食沙盘为简化模型（未含白道倾角 5.14° 的交点条件）。
